# TradeX — NSE Paper Trading Simulator

TradeX is a full-stack stock trading simulator for Indian **NSE** equities where users start with **₹1,00,000** in virtual INR, monitor real-time simulated price streams over Socket.IO, optionally rebase simulated prices using a manual NSE snapshot fetch, and execute atomic **BUY** / **SELL** market orders backed by PostgreSQL decimal accounting.

> **Disclaimer:** TradeX is a paper-trading simulator using virtual INR. Live price ticks are generated by a bounded random-walk simulation. The **LIVE NSE PRICES** button manually fetches a point-in-time NSE snapshot for reference and rebases the simulator; continuous ticks afterward remain simulated.

---

## Features

- **Real-Time Simulated NSE Market (`2.5s` ticks):**
  - Bounded mean-reverting random-walk simulation across 10 NSE stocks (`±0.45%` max tick, `±8%` max deviation from anchor, `500`-point rolling intraday history).
  - Live updates pushed via **Socket.IO** (`market:snapshot`, `market:price_update`) with REST hydration fallback and per-tick gain/loss flash animations (`LivePriceText`).
  - Periodic batched PostgreSQL persistence every `30s` (and on graceful shutdown) so simulated prices continue cleanly across server restarts.
- **Manual Live NSE Snapshot & Rebase (Zyla API):**
  - Clicking **LIVE NSE PRICES** manually fetches NSE data for all 10 configured stocks in parallel (`Promise.allSettled`), validates symbol aliases and price/change consistency, saves dedicated `nse_*` reference columns in PostgreSQL, rebases active simulated prices, and broadcasts updates without restarting simulation intervals.
  - Built-in single-flight duplicate-request lock (`409 Conflict`) and PostgreSQL-persisted global cooldown (`429 Too Many Requests`). Zero external API calls run on startup or timers.
- **Atomic Trading Engine (`MARKET` Orders):**
  - Clicking **BUY** / **SELL** opens a centered review modal (`OrderConfirmationModal`) displaying order type, quantity, reference price, estimated value, and available cash/holdings, then transitions inside the **same modal** to the **Order Executed** receipt on confirmation.
  - Backend resolves prices authoritatively on the server, performs all money arithmetic with `Prisma.Decimal`, and executes debit/credit, holding upserts/liquidations, order recording, and cash-ledger inserts inside `prisma.$transaction`.
- **Portfolio, Orders & Transactions Ledger:**
  - Live portfolio valuation (`Cash Balance`, `Invested Value`, `Holdings Value`, `Total Portfolio`, `Unrealized P&L`).
  - Order history (`/orders`) and cash ledger (`/transactions`, `BUY_DEBIT` / `SELL_CREDIT`) with segmented status/type filters and a custom calendar date popover (`DateFilterInput`).
- **Authentication & Onboarding:**
  - Email/password registration and sign-in (`bcrypt` + JWT) plus **Google SSO** (`google-auth-library` server-side ID token verification), atomically provisioning a `₹1,00,000` portfolio on first signup.

## Database Schema Overview

Six PostgreSQL tables managed via Prisma introspection (`backend/schema/schema.prisma`):

1. **`users`** — Accounts (`id`, `name`, `email`, nullable `password_hash`, nullable unique `google_id`, `is_active`).
2. **`portfolios`** — One portfolio per user (`user_id` unique, `cash_balance` defaulting to `100000.00`, `currency = "INR"`).
3. **`stocks`** — NSE equity records (`symbol`, `company_name`, `exchange`, `current_price`, `price_updated_at`, plus 14 nullable `nse_*` / `industry` / `market_cap_cr` / `quote_*` snapshot columns).
4. **`holdings`** — Active share positions per portfolio (`portfolio_id + stock_id` unique, `quantity > 0`, `average_price`).
5. **`orders`** — `BUY` / `SELL` execution log (`order_type`, `quantity`, `execution_price`, `total_amount`, `status`).
6. **`transactions`** — Immutable cash movement ledger (`order_id` unique, `BUY_DEBIT` / `SELL_CREDIT`, `amount`, `balance_after`).

## Getting Started

### Prerequisites

- **Node.js** `v20+` (developed on `v24.21.0`)
- **PostgreSQL** database (e.g., Supabase PostgreSQL) with the 6 TradeX tables and initial NSE `stocks` rows populated
- Optional: **Google Cloud OAuth Client ID** (for Google Sign-In) and **Zyla Indian Stock Exchange API key** (for manual NSE snapshot fetches)

### 1. Backend Setup

```bash
cd backend
npm install
cp .env.example .env
```

Configure `backend/.env` with your PostgreSQL `DATABASE_URL`, a strong `JWT_SECRET`, and optional keys (`GOOGLE_CLIENT_ID`, `ZYLA_API_KEY`).

Generate the Prisma client if needed and start the server:

```bash
npx prisma generate
npm run dev
```

Backend runs on `http://localhost:5000` by default.

### 2. Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Frontend runs on `http://localhost:5173` by default.

> **Google OAuth Note:** If using Google SSO locally, add `http://localhost:5173` under **Authorized JavaScript origins** in Google Cloud Console and set matching `GOOGLE_CLIENT_ID` (backend) and `VITE_GOOGLE_CLIENT_ID` (frontend).

## API & Socket.IO Reference

### REST Endpoints

| Group | Method & Path | Auth | Description |
|---|---|---|---|
| **Health** | `GET /api/health` | Public | Verifies API and PostgreSQL connectivity |
| **Auth** | `POST /api/auth/register` | Public | Registers user + creates ₹1,00,000 portfolio |
| **Auth** | `POST /api/auth/login` | Public | Email/password sign-in returning JWT |
| **Auth** | `POST /api/auth/google` | Public | Verifies Google ID token & signs in / registers |
| **Auth** | `GET /api/auth/me` | Bearer | Returns authenticated user profile & cash summary |
| **Market** | `GET /api/market/stocks` | Public | Lists all cached stocks + stored NSE snapshot fields |
| **Market** | `GET /api/market/stocks/:symbol` | Public | Returns latest quote & NSE snapshot for one stock |
| **Market** | `GET /api/market/stocks/:symbol/history` | Public | Returns in-memory intraday price history |
| **Market** | `GET /api/market/nse-status` | Public | Returns refresh lock, last fetch timestamp, cooldown |
| **Market** | `POST /api/market/nse-refresh` | Public | Manually fetches Zyla NSE quotes, updates DB & rebases simulation |
| **Orders** | `POST /api/orders/buy` | Bearer | Executes atomic MARKET BUY at current backend price |
| **Orders** | `POST /api/orders/sell` | Bearer | Executes atomic MARKET SELL at current backend price |
| **Orders** | `GET /api/orders` | Bearer | Lists authenticated user's orders |
| **Portfolio** | `GET /api/portfolio` | Bearer | Returns holdings & Decimal-computed live P&L |
| **Portfolio** | `GET /api/portfolio/transactions` | Bearer | Returns `BUY_DEBIT` / `SELL_CREDIT` ledger entries |

### Socket.IO Events

- **Client → Server:** `market:subscribe` (requests immediate `market:snapshot`)
- **Server → Client:**
  - `market:snapshot` — Full array of all 10 stock states sent on connect/subscribe
  - `market:price_update` — Broadcast every `2.5s` tick and immediately after a manual NSE rebase
